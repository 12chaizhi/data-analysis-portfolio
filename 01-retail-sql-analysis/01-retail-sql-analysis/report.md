# 电商零售订单SQL数据分析
## 一、项目背景
基于公开脱敏电商订单数据集，使用MySQL完成全流程商业数据分析，挖掘用户消费特征、区域销售差异、月度销售趋势，为电商运营提供决策参考。

## 二、数据集说明
字段介绍：
user_id：用户编号
order_id：订单编号
pay_amount：订单金额
create_time：下单时间
province：用户所在省份

## 三、分析内容与结论
1. **区域销售分析**
四川省总销售额排名第一，河南省次之；山东省整体销售额偏低，可针对性投放推广活动。
2. **月度销售趋势**
1–3月总销售额持续下滑，但订单数量保持稳定，说明客单价下降，需要推出组合套餐提升单笔消费金额。
3. **用户消费指标**
整体平均客单价偏低，可通过优惠券、满减活动刺激用户增加购买量。

## 四、业务优化建议
1. 对销量薄弱省份（山东）定向投放广告、新人优惠；
2. 上线捆绑销售商品，提高用户单次下单金额；
3. 针对高价值用户建立会员体系，提升复购。

## 五、技术工具
MySQL，多表查询、聚合函数、时间窗口统计
