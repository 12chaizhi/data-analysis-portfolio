# data-analysis-portfolio
## 个人简介
计算机专业大三在读，本仓库为完整数据分析实战作品集，用于数据分析实习求职、考研复试能力展示。
熟练使用 MySQL、Python(Pandas/Numpy/Matplotlib/Seaborn)、Tableau 完成全流程商业数据分析，具备完整业务分析思维。

## 📂 仓库项目目录（三大完整实战项目）
### 01-retail-sql-analysis 电商SQL实战项目
- 核心技术：MySQL，窗口函数、多表联查、留存率/漏斗转化/RFM分层计算
- 数据集：公开脱敏电商用户订单数据集
- 产出：完整可运行SQL代码、查询结果截图、业务分析报告

### 02-ecommerce-rfm-python Python用户分层分析项目
- 核心技术：Python Pandas/Numpy/Seaborn，数据清洗、EDA探索、RFM用户分群、相关性统计
- 业务场景：电商用户流失原因挖掘、高价值用户识别
- 产出：自动化分析代码、可视化图表（热力图/散点图/趋势图）、可落地运营优化方案

### 03-retail-dashboard-tableau Tableau BI可视化看板项目
- 核心工具：Tableau Public
- 看板模块：总GMV指标卡、用户转化漏斗、区域销量热力图、月度销售同比、用户分层消费对比
- 产出：完整看板截图、指标口径说明文档

## 🛠️ 技术栈
1. 数据库：MySQL，精通聚合查询、多表JOIN、窗口函数、时间序列指标计算
2. 数据分析：Python（Numpy、Pandas、Matplotlib、Seaborn）
3. 可视化工具：Tableau Public
4. 统计基础：描述统计、相关性分析、假设检验
5. 工程规范：Git版本控制、标准化项目目录、代码注释规范

## 📋 统一项目规范
每个子项目文件夹固定结构：

- 项目名 /
  - data/：存放公开脱敏数据集 csv 文件
  - code/：存放完整可运行 SQL/Python 源码
  - img/：存放可视化图表、看板截图、查询结果图
  - report.md：完整业务分析报告：背景→数据清洗→分析过程→可视化→业务落地策略
